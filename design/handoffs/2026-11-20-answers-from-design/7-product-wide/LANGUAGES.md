# Languages (Ulia, 20 Nov 2026)

- **No Russian.** There will be no Russian in noddo: no Russian UI strings, and no Russian slogan.
- **Other languages.** The product is localized into other languages. Every string is written in English first; the code translates it.
- **The slogan per language.** It keeps the meaning of "Every yes, handled.", and the last word is in Rose:

| Language | Slogan |
|---|---|
| German | Jedes Ja, erledigt. |
| French | Chaque oui, réglé. |
| Spanish | Cada sí, resuelto. |
| Portuguese | Cada sim, resolvido. |
| Italian | Ogni sì, sistemato. |
| Polish | Każde „tak” – załatwione. |
| Czech | Každé ano, vyřízeno. |
| Romanian | Fiecare „da”, rezolvat. |
| Ukrainian | Кожне «так» — вирішено. |
| Estonian | Iga jah, korras. |

A native check before launch is recommended.
